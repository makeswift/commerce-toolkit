Add category-card primitives subpath export. You can now import individual category card primitives via `commerce-toolkit/category-card`:

```tsx
import {
  Root,
  Icon,
  Thumbnail,
  Image,
  Fallback,
  Overlay,
  Title,
  Link,
  Skeleton,
} from 'commerce-toolkit/category-card';
```
